Cloud pricing

The term premium

What a cloud charges for a GPU by the hour, measured against what it accepts to lock the same machine away for three years. Below parity, the seller is renting it today, with no commitment, for less than it charges the customers who signed a three-year deal.

Method and limits

The measure is a ratio rather than a price because both legs are the same SKU, so GPU count, processor, memory and disk cancel out. No hardware specification table is needed and none can be got wrong, and each seller is compared only against its own committed book — which is what makes the three clouds comparable at all.

AWS spot is not an auction. It has been an administered, smoothed price since November 2017. This is a seller’s posted price, not an order book. Google’s spot prices are administered outright, reset by decision roughly monthly, so only their changes carry information, not their level.

A quoted price is not available capacity. A price is published for machines that cannot always be launched, so a low reading on a frontier part may describe a phantom market rather than a soft one. And the commitment leg is a list price that large buyers negotiate below, which pushes every ratio upward — so any reading under parity is the conservative case.

Method, collector and raw archive: github.com/kevinlam92/gpu-term-premium. Azure’s pricing API needs no credentials, so the headline number can be checked in a browser.
